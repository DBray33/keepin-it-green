# Keeping It Green Lawn Care Solutions

Professional lawn fertilization, pest control, and landscaping services in Berks County, PA.

## About

Keeping It Green Lawn Care Solutions provides soil-science-based lawn care, tree & shrub treatments, vegetation control, and landscaping for residential and commercial properties in Berks County and surrounding areas.

**Website:** [keepingitgreenls.com](https://keepingitgreenls.com)

## Tech Stack

- **Frontend:** HTML5, CSS3, vanilla JavaScript
- **Fonts:** Inter + Montserrat (Google Fonts)
- **Hosting:** Netlify
- **Forms:** Netlify Forms
- **Images:** Google Cloud Storage (`gs://kws-clientele/Keepin it Green/`)
- **CSS:** Single stylesheet (`css/styles.css`)
- **JS:** `js/main.js`
